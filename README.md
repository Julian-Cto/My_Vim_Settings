## instructions for NEOVIM
in ~/.config/ run `git clone git@github.com:Julian-Cto/My_Vim_Settings.git vnim`

## instructions for VIM
in ~/ run `git clone git@github.com:Julian-Cto/My_Vim_Settings.git vim`
copy init.vim into home/ and rename it to .vimrc, change colorscheme path in .vimrc to /path/colors/folder

## Color intructions
Make a file colled currentColor.vim in the main folder with the copied colorshceme of choice
.gitignore is preset to ignore this file to preserve colorschemes across machines
